# 家庭作业跟踪平台简要设计

## 1. 目标

设计一个面向两个儿童使用的家庭作业跟踪平台，用于管理和练习不同类型的学习任务，例如：

- 语文听写
- 数学题目
- 数学进制转换
- 后续可扩展的英语、口算、阅读打卡等任务

平台优先采用网页形式，儿童无需登录，直接在页面顶部或侧边切换当前儿童账号。每个小朋友的作业放在独立目录中，一般情况下每个任务就是一个独立网页。

## 2. 页面框架

整体采用左右布局：

```text
┌─────────────────────────────────────────────┐
│ 顶部：当前儿童切换 / 设置入口                 │
├───────────────┬─────────────────────────────┤
│ 左侧导航栏      │ 右侧任务网页区                 │
│               │                             │
│ - 语文听写      │  加载对应任务网页               │
│ - 数学题目      │  练习 / 开始 / 下一题 / 结果      │
│ - 进制转换      │  每个任务独立维护页面逻辑         │
│ - 更多任务      │                             │
└───────────────┴─────────────────────────────┘
```

## 3. 核心功能

### 3.1 儿童账号切换

- 固定支持两个儿童账号：`余晓`、`余跃`。
- 不需要登录、密码、注册。
- 页面中直接切换，例如：`余晓` / `余跃`。
- 切换后展示该儿童自己的任务进度和完成记录。

### 3.2 左侧任务导航

左侧展示当前小朋友目录下的可用任务网页：

- 语文听写
  - 对应一个独立网页，例如 `homework/yuxiao/chinese-dictation/index.html`
  - 选择课文或词语列表
  - 开始听写
  - 支持朗读、重读、下一词
  - 记录完成次数和日期

- 数学题目
  - 对应一个独立网页，例如 `homework/yuxiao/math-questions/index.html`
  - 展示题目
  - 输入答案
  - 判断正确/错误
  - 记录错题

- 数学进制转换
  - 对应一个独立网页，例如 `homework/yuxiao/base-conversion/index.html`
  - 十进制转二进制
  - 二进制转十进制
  - 可配置题目数量和难度

后续新增任务时，只需要在对应小朋友目录下新增一个任务网页，并加入任务配置。

## 4. 数据设计

前期可先使用浏览器本地存储 `localStorage`，不依赖后端。

### 4.1 目录结构

每个小朋友的作业独立放到一个目录中：

```text
SmartWay/
├── index.html                  # 平台入口，负责儿童切换和左侧导航
├── homework/
│   ├── yuxiao/                 # 余晓的作业目录
│   │   ├── tasks.json          # 余晓的任务列表配置
│   │   ├── chinese-dictation/
│   │   │   └── index.html      # 语文听写任务网页
│   │   ├── math-questions/
│   │   │   └── index.html      # 数学题目任务网页
│   │   └── base-conversion/
│   │       └── index.html      # 进制转换任务网页
│   └── yuyue/                  # 余跃的作业目录
│       ├── tasks.json
│       └── ...
└── shared/                     # 公共样式、工具函数、通用组件
```

原则：

- 每个小朋友一个独立目录。
- 一般情况下，一个任务就是一个独立网页。
- 首页只负责切换小朋友、展示导航、加载任务网页。
- 公共能力放到 `shared/`，避免每个任务重复实现。

## 5. 模块设计

### 5.1 应用外壳

负责整体布局：

- 顶部儿童切换
- 左侧导航栏
- 右侧任务网页区：通过 `iframe` 或页面跳转加载任务网页
- 当前任务状态管理

### 5.2 任务注册机制

任务注册以 `tasks.json` 为主，每个任务指向一个独立网页：

```js
{
  id: "base_conversion",
  title: "进制转换",
  entry: "./base-conversion/index.html",
  type: "quiz",
  enabled: true
}
```

首页读取当前小朋友目录下的 `tasks.json`，生成左侧导航；点击任务后，在右侧任务网页区加载对应 `entry`。

这样后续新增任务时，不需要修改主框架，只需要：

1. 在对应小朋友目录下新增任务网页目录
2. 在该小朋友的 `tasks.json` 中加入配置
3. 左侧导航自动展示

### 5.3 数据存储模块

统一封装本地存储：

- 保存当前儿童
- 保存任务进度
- 保存练习结果
- 读取历史记录
- 后续可替换为后端接口

## 6. 首期实现范围

第一阶段建议实现：

1. 两个儿童账号切换
2. 为 `余晓`、`余跃` 建立独立作业目录
3. 左侧导航读取当前小朋友的 `tasks.json`
4. 语文听写任务改造成独立任务网页
5. 数学进制转换任务原型独立成网页
6. 本地保存每个儿童的完成记录

暂不实现：

- 登录系统
- 云端同步
- 家长端复杂统计
- 多设备数据同步

## 7. 后续扩展方向

- 增加每日任务计划
- 增加错题本
- 增加学习日历
- 增加家长查看统计
- 增加任务难度配置
- 增加数据导出
- 后端化存储，支持多设备同步

## 8. 技术建议

当前项目可以先保持轻量实现：

- 入口页 `index.html` 负责整体框架
- 每个任务一个独立 `index.html` 网页
- 使用 `localStorage` 保存数据
- 按小朋友目录拆分作业内容
- 公共样式和工具函数放到 `shared/`

后续任务数量变多后，可升级为：

- `React + TypeScript`
- 组件化任务模块
- 独立数据服务层
- 可选后端数据库
